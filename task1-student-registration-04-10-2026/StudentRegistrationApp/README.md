## 🚀 Getting Started

### Project Creation

```bash
npx @react-native-community/cli@latest init StudentRegistrationApp
```

### Installation & Run

1. **Navigate to the project folder**:
   ```bash
   cd StudentRegistrationApp
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the Metro bundler**:
   ```bash
   npm start
   ```

4. **Run on Android**:
   ```bash
   npm run android
   ```
